# Resolve Móveis

Ferramenta de apoio ao SAC Pós-venda para identificar a tratativa correta de móveis durante o primeiro atendimento.

## Como usar

Abra `index.html` em qualquer navegador moderno. A aplicação é estática e não exige instalação, servidor ou acesso a banco de dados.

## Fluxos contemplados

- Busca nos fornecedores ativos informados pela operação.
- Alerta de atendimento direto para marcas exclusivas.
- Troca para ocorrências mapeadas em colchões, estofados e móveis de madeira.
- Pedido de peças com indicação da macro `BKO > peças`.
- Orientação especial sobre o vocabulário “quebrou”.
- Texto pronto para falar com o cliente e registro copiável para o Zendesk.
- Consulta rápida sobre mediações de Reclame Aqui, Procon e Consumidor.gov.

> A base deve ser atualizada quando as políticas operacionais ou a lista de fornecedores mudarem.
